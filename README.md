# Student Backlog

This repository contains the tasks, notes, and learning agreements for a
structured software-engineering study program. Each task is kept as a
Markdown document with an objective, requirements, deliverables, acceptance
criteria, and a self-check so that progress is observable and repeatable.

## Repository contents

| File                       | Purpose                                                                              |
| -------------------------- | ------------------------------------------------------------------------------------ |
| [`W00-02.md`](./W00-02.md) | Set up the Java, IntelliJ IDEA, Git, and GitHub environment.                         |
| [`W00-03.md`](./W00-03.md) | Define the AI protocol, Definition of Done, privacy rules, and language conventions. |
| [`W01-01.md`](./W01-01.md) | Read Chapter 1 of _Modern Software Engineering_ and write a learning summary.        |

The backlog will grow as new weekly tasks are added. Task files are the
source of truth for the requirements of each exercise.

## Working process

For each task:

1. Read the objective, requirements, and acceptance criteria.
2. Make an independent attempt before requesting help.
3. Work in small, meaningful changes.
4. Verify the result against the requirements and self-check.
5. Record the change with a clear English commit message.
6. Review the implementation and make sure the result can be explained.

The normal Git loop is:

```text
edit → git status → git add → git commit → git push
```

Commits should represent meaningful changes rather than an artificial commit
count.

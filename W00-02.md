# W0-2: Environment Setup — JDK + IntelliJ + Git + GitHub

> **ID:** W00-02 | **Week:** 0 | **Type:** Setup
> **Deliverable:** GitHub repo

## Objective

Set up the complete working environment you will use for the whole program: a Java JDK, the IntelliJ IDEA IDE, Git, and a GitHub account. You will create your first repository, `phase-1-java`, and practice the basic Git loop you will repeat every day: **edit → status → commit → push**. A working environment is the foundation of every later task, so you must verify the core commands all run from a terminal before W3. If something is broken, you fix it now — not in the middle of a coding task later.

## Requirements

### 1. Install the tools

- Install a **JDK** (Java Development Kit). After installing, `java -version` and `javac -version` must both work in a terminal.
- Install **IntelliJ IDEA** (the Community Edition is enough) and open it once to confirm it runs.
- Install **Git** and configure your identity: `git config --global user.name` and `git config --global user.email`, so your commits are attributed to you.
- Make sure you have a **GitHub** account.

### 2. Create and prepare the repository

- Create a repository named **`phase-1-java`** on GitHub and clone it to your computer.
- Add a **README** that briefly explains what this repository is for.
- Add a **`.gitignore`** that suits a Java + IntelliJ project. Find out what it should ignore (IDE files, compiled output, and similar) and why.

### 3. Practice the Git loop

- Practice the daily loop several times: make a small edit → `git status` → `git add` → `git commit` → `git push`.
- Every commit must represent **one meaningful change** and have a clear message in English.
- Do not create fake or empty commits just to reach a commit count. A small number of meaningful commits is exactly right.

### 4. Verify the CLI checklist

From a terminal, verify that you can do all of the following:

- Open a terminal on your own.
- Navigate directories: `cd` to change directory, `dir` to list contents.
- Run `java -version` and `javac -version` without errors.
- Run `git status`, `git add`, `git commit`, and `git push` without errors.

## Deliverables

- A GitHub repository named `phase-1-java`, containing a README and a `.gitignore`, with a few meaningful commits pushed to it.
- The repository link, submitted as the result of this task.

## Acceptance Criteria

- The repository exists on GitHub and contains both a README and a `.gitignore`.
- You can add, commit, and push completely on your own — no help, and no commands you cannot explain.
- You can explain, in your own words, the current state of your repository: what `git status` tells you, what is staged, and what your last commit changed.

## Self-Check

- [ ] `java -version` and `javac -version` run without errors in a fresh terminal.
- [ ] `phase-1-java` exists on GitHub and is cloned locally.
- [ ] My README explains what the repository is for.
- [ ] My `.gitignore` ignores IDE and build files, and I can explain why.
- [ ] Every commit I pushed is a real change with an English message.
- [ ] I can run the full loop — edit → status → commit → push — from the terminal without help.
- [ ] I can explain my repository state (what is staged, what the last commit changed) using `git status`.

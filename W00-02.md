# W00-02: Development Environment Setup

**Goal:** Set up your Java development environment and learn how to use Git and GitHub to save and track your code.

## Tasks

### 1. Set Up Java and IntelliJ IDEA

- Install the required JDK.
- Check that Java works using `java -version` and `javac -version`.
- Install IntelliJ IDEA and connect it to your JDK.
- Create a simple Java project (print "hello world") and run it successfully.
- Learn the basic roles of the JDK, JVM, JRE, and IDE.

### 2. Set Up Git and GitHub

- Install Git and configure your username and email.
- Create a GitHub account.
- Create a GitHub repository named `phase-1-java`.
- Connect your local project to the GitHub repository.
- Create a `README.md` file contains "system.out.print("hello world").
- Create a suitable `.gitignore` file for Java and IntelliJ IDEA.

### 3. Practice the Git Workflow

Practice the following steps by making a real change to your project:

1. **Edit:** Change a file in your project.
2. **Status:** Use `git status` to check the changes.
3. **Diff:** Use `git diff` to review the changes.
4. **Stage:** Use `git add` to prepare the files.
5. **Commit:** Use `git commit` with a clear message.
6. **Push:** Use `git push` to upload your changes to GitHub.
7. **Verify:** Check GitHub to confirm that your changes were uploaded.

Use meaningful commits that describe real changes.

## Check Your Understanding

- Explain the difference between a local repository and a remote repository.
- Understand the purpose of `git status`, `git diff`, and `git log`.
- Explain the difference between modified and staged files.
- Be able to check your repository status and push changes without step-by-step help.

## Acceptance Criteria

- [ ] Java and IntelliJ IDEA are installed and working.
- [ ] A simple Java project runs successfully.
- [ ] A GitHub repository named `phase-1-java` exists and is connected to the local project.
- [ ] The project contains a useful `README.md` and a suitable `.gitignore`.
- [ ] You can edit, review, stage, commit, and push changes successfully.
- [ ] You can explain the basic Git workflow and check your repository status independently.
- [ ] Your commits describe real changes.
- [ ] No passwords or secret keys are uploaded to GitHub.

## Deliverables

- GitHub repository: `phase-1-java`
- A working Java project.
- `README.md` and `.gitignore` files.
- A meaningful commit history showing your changes.

## Definition of Done

You have completed this task when your environment and repository are ready, your Java project runs successfully, and you can use the basic Git workflow independently and explain what each step does.
